# Reuse Note

Note kind: non-authoritative reuse note

This file is not acceptance evidence.

The current candidate uses the shared CircularAreaBackingResource at every ordinary API boundary. Read callers own UCharArray.full buffers; empty Read returns 1 unchanged, live Read returns 0 with the consumed byte. Non-force Write returns 0 and status 1. The force harness is intentionally isolated: its callee post is raw, and only the fresh four-byte/exactly-four-byte case is explicitly re-established as canonical before Release.

Authoritative evidence and exact hashes are in agent_report.json; the JSON handoff, current worktree, and controller results win over this note.
