# CS_AttCtrl_Propel 浮点差分测试

本交付直接编译原始 `IP_CS_AttCtrl_Propel.c`，覆盖模式参数选择、三轴交叉
喷管调度/顺序更新，以及忽略零值的极值位置搜索。输出同时比较 binary64
持续时间位型、喷管选择状态和极值下标。

固定种子结果为 **1014/1014**（14 条定向 + 1000 条随机）正例通过，另有
1 条阴性控制。三类目标分别为配置 330、交叉控制 358、极值搜索 326 条；
配置函数的五种结果全部命中，交叉控制 84 条发生状态更新，极值搜索覆盖
长度 0..6，其中 52 条保持“未找到非零元素”的哨兵结果。全新临时 gcc
构建生成的向量与归档文件逐字节一致。

相平面控制、喷管脉冲计算和 12 喷管分配不属于本批测试结论。

复现：

```sh
bash FloatTest/tools/run_tests.sh CS_AttCtrl_Propel 1000 0x13198a2e03707344
```

这是有限采样位级差分测试，不是全称证明，也不覆盖内存安全。
