# Reuse Note

Note kind: non-authoritative reuse note

This file is not acceptance evidence.

The candidate uses the public decomposition `xizi_dll(head, prefix ++ anchor :: suffix)` and the exact result `prefix ++ anchor :: fresh :: suffix`. Both fresh-node fields require only `undef_data_at`, with no named old values.

The essential repair was a local two-case ownership view. When `suffix = nil`, the overwritten successor-prev field is the sentinel's prev field; when `suffix = old_next :: rest`, it is the first suffix node's prev field. Keeping those cases explicit lets symbolic execution validate the unchanged C assignments and leaves three semantically provable manual witnesses.
