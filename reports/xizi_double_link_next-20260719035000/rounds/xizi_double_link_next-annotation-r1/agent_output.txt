# Reuse Note

Note kind: non-authoritative reuse note
This file is not acceptance evidence.

The candidate keeps the public contract at the shared abstraction level: `xizi_dll(head, nodes_before ++ node :: nodes_after)` is preserved, and `xizi_double_link_next_value nodes_after` gives the exact result (zero for the last node, otherwise the first suffix address).

The implementation needs ownership of the selected node fields even when it is in the middle of the abstract list. One local full `Assert` derives the sentinel/prefix/node/suffix decomposition using `xizi_dllseg`; this produced one intentional manual entailment witness and lets symbolic execution reach the file end. The two return witnesses are the empty/nonempty suffix cases and are semantically provable by segment split/concat plus the guarded nonempty segment condition.

The local qcp-mcp wrapper cannot transport canonical `-I`/`-slp` arguments. Interactive checks therefore used a reversible expansion of the target's own header and an absolute pointer to the same worktree strategy; the final source was restored to `#include "xizi_double_link_def.h"`. Canonical symexec separately passed with the exact handoff arguments.

The case lib adds only the pure observation `xizi_double_link_next_value`; no representation predicate, proof helper, Axiom, or algorithm mirror was added.
