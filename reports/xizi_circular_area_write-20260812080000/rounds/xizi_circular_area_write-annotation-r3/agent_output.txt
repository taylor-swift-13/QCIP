Reusable spec design:

- Represent legal ring states with capacity/index/status bounds, physical byte-list length, and a logical FIFO observation for empty, full, contiguous, and wrapped states.
- Model a physical copy as an extensional slice update (`prefix ++ source-slice ++ suffix`) and model ring write as either one slice update or two consecutive slice updates.
- Successful write uses `actual = min(request, capacity - old_length)`, updates `writeidx` modulo capacity, sets status to one, and sets `readidx = new_writeidx` only in force mode.
- Non-force success should explicitly state `new_logical = old_logical ++ sublist 0 actual input`.
- Full non-force returns unsigned ERROR and preserves all state. Full force follows the current implementation: free capacity is zero, so it copies zero bytes and then makes `readidx = writeidx`.
- Null area, null input, and zero request are separate error specs and preserve owned state whenever ownership exists.
- Helper callable specs for IsFull/GetDataLength/DivideWrData can be derived from the valid main-state precondition; GetDataLength's specialization must preserve the pure representation fact.
